# 壁纸时移 · 参考图到导入包

交付真实生成的图片和一个可导入的 `.zip`，不只交付提示词。此技能独立于项目源码，可复制到其他 Agent 的技能目录。需要图像生成/编辑工具、Python 3.10+ 和 Pillow（`python -m pip install Pillow`）。工具不可用时说明缺少的能力，不用占位图冒充成品。

## 从参考图生成一套图

先查看用户提供的每张参考图，提取主体、位置、镜头、地平线、画风和材质。尊重用户指定的场景、张数、时间与屏幕尺寸；未指定时用以下默认值直接开始，并简要告知用户：

- 同一场景六张：黎明 05:00、早晨 07:30、正午 11:00、午后 14:00、日落 17:30、夜晚 19:30。
- 竖屏 9:19.5，推荐交付 1440×3120；桌面模糊强度 10。目标设备比例已知时优先匹配设备。
- 主体放在中下部，上方约四分之一保留低细节空间给系统时钟；避免关键内容贴边。图片里不画时间、文字、水印、图标、手机边框或 UI。

使用当前 Agent 可用的图像生成/编辑工具，并遵循该工具自己的调用约定。每次生成都实际传入用户参考图；如果工具支持多图参考，可额外传入已选定的一张生成图来稳定构图。不要只靠文字回忆参考图。参考图无法访问时请用户重新提供；不要假装已经看过。

每个时段生成一张独立、清晰的壁纸，不生成六格拼图。固定视角、主体身份、尺度、建筑/地形位置和画风，只改变时间、光线、天空、阴影、窗灯与合理的环境状态。夜景仍需能辨认主体。默认保持参考图主体；用户授权重新设计时再改构图。多张参考图有冲突时，按用户指定的用途分工；只有无法合理判断主参考图时才询问。

提示词可采用这种骨架，再补上实际观察到的细节：

> 以附图为视觉参考，制作同一场景的「{时段}」手机壁纸。保持 {主体及其位置、镜头、画风、固定地标}，仅将光照和环境改为 {该时段的具体变化}。单张完整竖屏画面，目标比例 {比例}，主体完整，上方给系统时钟留出安静空间，无文字、无 UI、无拼图。

工具不支持目标尺寸时，先生成最接近的竖图，确保主体位于最终安全裁剪范围内；打包脚本会居中裁剪、缩放并报告裁剪和放大。明显不合比例时优先重新生成或用图像工具扩图，不能靠拉伸凑尺寸。

查看所有实际输出，检查跨图一致性、时段差异、画面瑕疵和裁剪安全；有问题就有针对性地重做。保留未经模糊的原图：APP 自动制作桌面模糊图，每个时段只需一张源图。

## 制作和验证导入包

阅读 [references/package-format.md](references/package-format.md)，尤其是大小限制和 `anchor` 语义。在工作目录保存生成图片和 `plan.json`。计划中的 `file` 相对计划文件所在目录，例：

```json
{
  "name": "海边的一天",
  "blur": 10,
  "items": [
    {"file": "generated/dawn.png", "start": "05:00", "label": "黎明"},
    {"file": "generated/morning.png", "start": "07:30", "label": "早晨"},
    {"file": "generated/noon.png", "start": "11:00", "label": "正午"},
    {"file": "generated/afternoon.png", "start": "14:00", "label": "午后"},
    {"file": "generated/sunset.png", "start": "17:30", "label": "日落"},
    {"file": "generated/night.png", "start": "19:30", "label": "夜晚"}
  ]
}
```

执行技能目录下的脚本（将 `<skill-dir>` 替换为本技能实际路径）：

```bash
python <skill-dir>/scripts/package_set.py build --plan /absolute/work/plan.json --output /absolute/work/海边的一天.zip
python <skill-dir>/scripts/package_set.py check /absolute/work/海边的一天.zip
```

`build` 处理 EXIF 方向，将透明部分铺为白底，统一为 RGB JPEG（质量 95），去掉源图元数据，在 ZIP 根目录写入真实导入清单并自动校验。用 `--size 1080x2340` 等覆盖默认尺寸。脚本拒绝覆盖已有输出，换名保存。检查器专门验证本技能产物，比 APP 接收任意第三方包的规则更严格。

查看 ZIP 内最终处理后的图片，确保裁剪后主体完整；程序校验不能代替视觉检查。交付 ZIP 的可下载链接和简短时间表，可附预览；不要把计划文件或技能安装包误当作壁纸包。若发生放大，说明生成原图尺寸和最终尺寸，不把插值当作原生分辨率。

告诉用户：把 ZIP 保存到手机 → 壁纸时移首页「导入」→ 选择 ZIP → 检查时间表并启用。导入后默认不启用，也可从文件管理器以「壁纸时移」打开 ZIP。不要声称已在真机导入，除非实际验证过。
